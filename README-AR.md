# إذاعة القرآن الكريم — تطبيق أندرويد (APK)

نفس الإضافة بنفس الشكل والأيقونة، متحولة لتطبيق أندرويد (Capacitor).
- التشغيل بيكمل والشاشة مقفولة (Foreground Service مع إشعار فيه زرار إيقاف).
- زرار الرجوع بيصغّر التطبيق بدل ما يقفله، عشان الصوت يفضل شغال.
- لو البث فصل بيحاول يوصل تاني تلقائياً.

## طريقة بناء الـ APK على GitHub (من غير ما تنزل أي حاجة على جهازك)

1. اعمل حساب على https://github.com لو معندكش.
2. اضغط **New repository** → اكتب اسم (مثلاً `quran-radio`) → **Create repository**.
3. من صفحة الريبو الجديد اضغط **uploading an existing file**.
4. فك ضغط الملف ده، وافتح مجلد `QuranRadioApp`، **حدد كل اللي جواه** (مش المجلد نفسه) واسحبه للصفحة.
   - لازم يظهر مجلد `.github` و`android` و`www` وملفات `package.json` و`capacitor.config.json`.
   - لو مجلد `.github` مختفي عندك على الويندوز: من تبويب View فعّل **Hidden items**.
   - لو الرفع بالسحب مرفضش المجلدات الكبيرة، ارفع على دفعات (كل دفعة أقل من 100 ملف) أو استخدم GitHub Desktop.
5. اضغط **Commit changes**.
6. افتح تبويب **Actions** — هتلاقي شغل اسمه **Build Android APK** شغال لوحده (5–10 دقايق).
   لو مبدأش: اختاره من القائمة اليسار واضغط **Run workflow**.
7. لما يخلص (علامة ✅) افتحه، وفي آخر الصفحة تحت **Artifacts** نزّل **QuranRadio-APK**.
8. فك الـ zip اللي نزل، هتلاقي `QuranRadio.apk`.

## التثبيت على Redmi A3
1. انقل الـ APK للموبايل وافتحه.
2. لو طلب، اسمح لمتصفحك/مدير الملفات بـ **تثبيت تطبيقات من مصادر غير معروفة**.
3. لو ظهرت رسالة Play Protect اضغط **Install anyway**.
4. أول تشغيل اسمح بالإشعارات (مهمة عشان التشغيل في الخلفية).

## مهم جداً لأجهزة Xiaomi/Redmi (عشان الصوت ميقطعش والشاشة مقفولة)
- الإعدادات ← التطبيقات ← إدارة التطبيقات ← Quran Radio ← **Battery saver / توفير الطاقة** ← اختار **No restrictions / بدون قيود**.
- فعّل **Autostart** للتطبيق.
- افتح التطبيق في الـ Recents واضغط على الأيقونة ← **Lock / قفل** عشان النظام ميقفلوش.

## تعديلات
- عدّل أي حاجة في مجلد `www` (القائمة في `www/app.js`، الشكل في `www/style.css`)، ارفع التعديل على GitHub والـ APK الجديد بيتبني تلقائياً.
- الخطوط (Cairo/Amiri) بتتحمل من الإنترنت زي الإضافة بالظبط.
- الـ APK ده Debug موقّع بمفتاح تجريبي، كويس للاستخدام الشخصي ومش للنشر على Google Play.
